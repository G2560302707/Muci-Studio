# 图片物料标准（抖音 × 小红书，2026-11-15 口径）

> **本文件是图片物料规格的唯一事实源（SSOT）。**
> 隔离规则：其他 skill、README、START-HERE、AGENTS/CLAUDE 等文档**只允许引用本文件路径，不得复制具体数字**（比例/尺寸/安全区）。平台改版时只改本文件，引用处零改动。治理依据：根 README「规则 8 · 标准隔离」。

## 何时用我（trigger）

- 每期成片过审后出**发布物料（封面图）**时
- 小红书图文笔记做封面/配图时
- 一切"要产出一张图"的任务（封面、配图、海报位图），拿不准比例/安全区/命名时

## 需要什么（required assets）

- 成片或定稿关键帧（`作品库/epNN-*/assets/keyframes/` 或 `final-frames/`）
- 该期 `epNN/README.md` 的画幅声明（竖屏 9:16 还是横屏 16:9）
- 发布目标平台清单（抖音 / 小红书 / 双发）

## 一张表定尺寸（唯一口径，别引网上其他数字）

| 场景 | 最优比例 | 出图尺寸 | 展示行为 |
|---|---|---|---|
| **小红书·主推封面**（图文+视频笔记通用） | **3:4** | **1242×1656** | 官方最推荐：发现页双列瀑布流占屏最大 |
| 小红书·备选方形 | 1:1 | 1080×1080 | 非 3:4 一律被居中裁切填卡片 |
| 小红书·备选横版 | 4:3 | 1440×1080 | 展示面积最小，仅横图内容必要才用 |
| **抖音·封面设计画布** | **3:4** | **1242×1660** | 封面卡/主页/搜索实际按 3:4 展示 |
| 抖音·直接用成片竖屏帧当封面 | 9:16 | 1080×1920 | 上下被裁成 3:4，见下方安全区 |
| 抖音·横屏视频封面 | 16:9 | 1920×1080 | 直接用成片帧；横屏视频 feed 居中播放、上下黑/模糊填充 |
| 抖音·直播间封面（备用） | 1:1 | 800×800 | — |

**两条铁律：**
1. **小红书封面没有 9:16**——封面只能选 3:4 / 1:1 / 4:3；视频本身可以 9:16 全屏，但封面不行。9:16 图直接当封面会被强制裁切或选不了。
2. **抖音封面的实际展示口径是 3:4**——竖屏 9:16 只在"直接拿视频帧当封面"时成立，且上下会被裁。

## 裁切链与安全区（核心避坑知识）

**抖音 A 案：成片帧直接当封面**（1080×1920）
- 信息流封面卡裁成 3:4 → 上下各丢约 240px（等效）
- 个人主页作品格再裁 ≈1:1 → 再丢 360px
- **安全区 = 中央 1080×1080（竖向 56%）**：标题字横向可满宽，纵向必须落在画面中央 56% 内；上下各 ≥420px 只放背景/氛围。

**抖音 B 案：自制封面图**（1242×1660 画布，推荐）
- 主页 ≈1:1 裁切 → 上下各裁 ~209px
- **安全区 = 竖向中央 75%（1242×1242 区域）**，上下各留 ~209px 放氛围。

**小红书 3:4 原生无裁切**：文字可满幅，四周留 ~6% 呼吸边；首图大字 ≤10 字/行、≤2 行；笔记标题上限 20 字。

**相关（视频画面本身，非封面）**：抖音播放页右侧 ≈150px 有点赞/评论浮层、底部 ≈250px 有文案/音乐区——**成片设计**时右侧底部避让关键信息（经验值）。

## 出图步骤（process）

1. 从成片 `final-frames/` 选代表帧，拷为 `epNN-cover-src.png`（**不拉伸不变形**）
2. 按平台分别**重排重绘**（文字按目标比例重新排版，不是缩放）：
   - 抖音 9:16 期：出 `epNN-cover-dy-916.png`（1080×1920，字在中央 56%）或 B 案 1242×1660
   - 小红书：出 `epNN-cover-xhs-34.png`（1242×1656）；横屏期另出 `epNN-cover-xhs-43.png`（1440×1080）
3. 缩略图自检：把图缩到手机双列瀑布流大小看大字是否可读
4. 登记进该期 `meta.json` / SKILL.md 的发布物料清单

## 交付检查表（checklist）

- [ ] 小红书封面是 3:4（不是 9:16、不是 16:9）
- [ ] 抖音封面标题字在裁切安全区内（A 案中央 56% / B 案中央 75%）
- [ ] 一篇小红书笔记所有图**同一比例**
- [ ] 大字 ≤2 行、缩到缩略图仍可读
- [ ] 没有拉伸变形（对比 src 帧人脸/产品轮廓）
- [ ] 封面用真实素材/成片帧，无 AI 假图（沿用 START-HERE 第 3 步素材铁律）

## 产出位置与命名（output）

```
epNN/assets/docs/cover/
├── epNN-cover-src.png       抽帧原图（留档，不发布）
├── epNN-cover-dy-916.png    抖音竖版封面 1080×1920
├── epNN-cover-dy-34.png     抖音自制画布 1242×1660（走 B 案时）
├── epNN-cover-xhs-34.png    小红书主推 1242×1656
└── epNN-cover-xhs-43.png    小红书横版 1440×1080（横屏期才出）
```

## 避坑清单（每条都真实翻车或高概率翻车）

1. ❌ 拿 9:16 成片帧直接当小红书封面 → 平台不收这个比例
2. ❌ 抖音封面标题字放顶部/底部 → 主页 1:1 裁切后只剩空白
3. ❌ 一篇小红书多图混比例 → 发布器强制统一，排版全乱
4. ❌ 拉伸 16:9 帧凑 3:4 → 人脸变形；重排不拉伸
5. ❌ 封面小字密排 → 双列瀑布流缩略图根本读不清
6. ❌ 横屏期只出横封面 → 抖音竖版封面曝光更大，能出竖版包装就出
