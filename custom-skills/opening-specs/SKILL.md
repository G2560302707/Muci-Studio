# 开场 5 秒规范（0–5s 母版 + 验收）

> **本文件是开场段规范的唯一事实源（SSOT）。**  
> 其他文档只引用本路径，不复制具体数字。只管成片开头 **0–5 秒**。

## 何时用

- 每期开场段写分镜、做首帧、交审前  
- 复盘完播 / 跳出数据，定位开场问题时  
- 封面定稿后，与成片首帧做同源核对时  

## 反面症状（避免）

- 第 0 帧只有白窗 + 单卡 + 一行字幕（可见对象 <3）  
- 开场缓入导致头 0.5s 几乎静止  
- 封面与成片首帧两套视觉互不相认  
- 钩子只卖空悬念，不给观众明确利益  
- 0–5s 无信息密度递进  

## 开场母版（五条）

### 1. 首帧与封面同源

封面和成片第 0 帧必须同一套视觉：同主色/底色、同主体、同字体气质。

### 2. 帧 0 即满，0.5s 内必须有动

- 第 0 帧可见对象 **≥3 个**  
- 前 **0.5s** 内必须有可见位移 / 缩放 / 淡入  
- 开场入场不用起点静止的缓入；淡入/入场用开头即快的缓动  

### 3. 钩子给利益，不卖空悬念

前 2–3s 讲清**看完能得到什么**。

### 4. 0–5s 信息逐拍递进

不能整段停在同一画面；每拍与口播所指一致。

### 5. 视觉身份跨物料一致

开场标题字、徽章、主体形象与封面、主页头像同一身份。

## 开场验收清单

- [ ] 首帧与封面主色/主体/字体同源  
- [ ] 帧 0 可见对象 ≥3  
- [ ] 前 0.5s 有可见动效  
- [ ] 前 3s 钩子给出明确利益或痛点对照  
- [ ] 0–5s 信息逐拍递进  
- [ ] 开场每拍与口播所指一致  
- [ ] 手机缩图档下开场大字仍可读  

## 边界

- 不规定必须用哪个组件；组件选择走编排白名单 / 自由拼接流程。  
- 素材真实 / AI 授权、音量、手机端可读性：见 `START-HERE.md` 第 3 步。
