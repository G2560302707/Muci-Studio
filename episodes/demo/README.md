# demo · 幕次 Studio 样例期

**形态**：默认 ②′ 整片模板（Remotion 出 MP4）  
**画幅**：横屏 16:9 · **风格**：白窗紫 · **题材**：知识

本目录是**策划与素材位**；场景代码在：

`muci-engine/components/src/demo/`

## 文件

| 路径 | 用途 |
|---|---|
| `plan.md` | 口播要点 |
| `assets/` | 截图 / B-roll（样例可空） |
| `audio/` | 配音 wav（样例可空，预览用字幕轴） |
| 引擎侧 `demo.config.json` | 成片参数真源 |
| 引擎侧 `demo.motion-map.json` | 选卡结果 |

## 怎么跑

在仓库根目录（安装完成后）：

```bash
npm run demo
```
