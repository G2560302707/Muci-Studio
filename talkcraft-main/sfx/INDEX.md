# SFX 音效库 · 索引

UI 动效音效包（ffmpeg 程序合成，**零版权风险**，商用/抖音可直接用）。
生成命令见 `generate.sh`，改参数重新生成即可。

## 音效清单

| 文件 | 时长 | 声音特征 | 典型用途 |
|---|---:|---|---|
| `pop.mp3` | 0.09s | 短促气泡弹出（620Hz 快衰减） | 胶囊/卡片弹出、按钮、勾选 |
| `whoosh-045.mp3` | 0.45s | 短扫动（粉噪声带通+渐变） | 单次素材切换、小位移 |
| `whoosh-100.mp3` | 1.00s | 长扫动（渐强渐弱） | 连排卡片过焦、整排滑入、页面切换 |
| `ding.mp3` | 0.45s | 清脆铃声（1318Hz 自然衰减） | 数字滚动落定、状态确认 |
| `stamp.mp3` | 0.16s | 低频闷响（150Hz） | 大标题/徽章盖印、章节落定 |

## 使用规范

- 音量垫在配音之下：Remotion `volume` 0.26–0.45，**配音永远最上层**
- 只在关键节拍出声（弹出/过焦/落定/盖印），其余动效刻意留白——全响=很吵
- 过焦/连排节拍用 pop + whoosh 叠加；大元素落定用 stamp；数值到位用 ding

## 再生成

```bash
bash generate.sh   # 输出全部 5 个 mp3 到本目录
```

## 部署

项目使用时拷贝（或引用）到渲染工程 `public/media/<ep>/sfx/`。
